    Сетевые адреса эндпоинтов

    • GET /api/hello — текстовое приветствие
    • GET /api/server-info — JSON с информацией
    • GET /api/sum?a=..&b=.. — сумма
    • GET /api/divide?a=..&b=.. — деление с обработкой ошибок
    • POST /api/echo — анализ переданного текста
    • GET /api/tasks — список задач (пагинация, фильтрация, сортировка)
    • POST /api/tasks — создание задачи (201 + Location, X-Api-Key)
    • PUT /api/tasks/{id} — обновление isDone / title (X-Api-Key)
    • DELETE /api/tasks/{id} — удаление задачи (204, X-Api-Key)
    • GET /api/tasks/search?q=... — поиск задач
    • GET /api/tasks/categories — список категорий с TaskCount
    • GET /api/unknown — демонстрация JSON 404 с кодом ошибки

    Все ошибки возвращаются в формате {"error":{"message":"...","code":"ERROR_CODE"}}. Для изменяющих методов /api/tasks требуется заголовок X-Api-Key.
